# Daily Cup — кофейный клуб

## Контрольная работа №3

Тема: «Адаптивная вёрстка и доступность многостраничного HTML/CSS-сайта».

## Описание

Daily Cup — учебный сайт кофейного клуба с каталогом кофеен города.
Каталог фильтруется по району, цене капучино и способу заваривания.
Каждая кофейня получает от клуба оценки по четырём критериям —
вкус, бариста, атмосфера, цена — и собирает отзывы и фотографии;
на главной публикуется топ месяца. Посетитель может оценить кофейню,
где уже побывал, или предложить новую.

Все шесть кофеен, адреса, часы работы и исходные отзывы вымышлены:
это учебный проект. Фотографии настоящие, но иллюстративные
и не изображают указанные заведения; авторы перечислены на странице
«О клубе» и в разделе ниже.

Бэкенда нет: отзывы и предложения посетителей сохраняются в браузере
(localStorage), видны только на этом устройстве и не отправляются
на сервер. На страницах это написано прямо.

## Технологии

- HTML5 (семантика, `<picture>`, `<dialog>`, формы);
- CSS3 (Custom Properties, Flexbox, Grid, медиазапросы Mobile First);
- ванильный JavaScript без библиотек;
- без Bootstrap и других фреймворков.

## Подключение стилей

На каждой странице:

```html
<link rel="stylesheet" href="css/style.css">
<link rel="stylesheet" href="css/responsive.css">
```

`responsive.css` подключён после `style.css`, чтобы адаптивные правила
переопределяли базовые. Viewport присутствует на всех страницах.

## Адаптивные решения

- Подход **Mobile First**: базовые стили для телефона, расширение
  через `@media (min-width: …)`.
- Проверенные ширины: **360, 430, 768, 1024 и 1440 px** —
  горизонтальной прокрутки страницы нет ни на одной.
- **Навигация:** на мобильном меню скрыто под кнопкой «Меню»
  (`aria-expanded`, закрытие по Esc и по клику на пункт);
  на desktop меню всегда видно.
- **Сетка карточек:** 1 колонка на телефоне, 2 на планшете (768 px),
  3 на desktop (1024 px), 4 на широком экране (1440 px).
- **Каталог:** на мобильном фильтр сворачивается кнопкой «Фильтры»
  (`aria-expanded`); на desktop — боковая колонка шириной 220 px.
  Фильтры по району, цене и способу заваривания работают вместе,
  синхронизируются с адресом страницы, есть состояние «ничего не найдено».
- **Изображения:** `max-width: 100%`, `height: auto`; для всех фото
  `<picture>` с WebP и JPG-запасом + `srcset`/`sizes` (480 / 960 / 1440 px).
  Проверено через вкладку Network: на 360 px грузится файл 480w,
  на 1440 px — файл 960w для hero-блока.
- **Формы:** на мобильном одна колонка, на desktop — две.
- **Таблица оценок:** на мобильном каждая строка превращается в карточку
  (`data-label`, семантика сохранена явными ролями таблицы), на desktop
  обычная таблица. Горизонтальной прокрутки страницы нет.
- Учёт `prefers-reduced-motion`.

## Доступность

- Ссылка «Перейти к содержимому» (skip-link).
- Видимый фокус `:focus-visible` на всех интерактивных элементах.
- Один `h1` на странице, логичный порядок заголовков, навигация в `nav`.
- У всех полей есть `label`; ошибки связаны через `aria-describedby`,
  ошибочные поля помечаются `aria-invalid` и текстом ошибки.
- Осмысленные `alt`; декоративные изображения с пустым `alt`.
- Контраст текста и элементов интерфейса соответствует требованиям.
- `<dialog>` закрывается по Esc, кнопке «×» и клику по фону;
  фокус возвращается к кнопке открытия.
- ARIA используется только где нужно (счётчик результатов —
  `role="status"`, мобильная таблица).
- Lighthouse, категория Accessibility: **100 / 100 / 100**
  для `index`, `catalog`, `order`. Отчёты — в `lighthouse/`.

## Как проверить

1. Открыть `index.html` через любой статический сервер
   (например, `python3 -m http.server`) — так корректно работают
   `localStorage` и загрузка изображений.
2. Главная: «Топ месяца» ведёт на страницы кофеен;
   в DevTools проверить ширины 360–1440 px.
3. Каталог: выбрать район + цену + способ заваривания —
   список и счётчик обновляются; несовместимые фильтры показывают
   состояние «ничего не найдено» и кнопку сброса.
4. Страница кофейны: фото открывается в диалоге (Esc закрывает),
   таблица оценок перестраивается в карточки на телефоне.
5. «Участвовать»: отправить пустую форму — ошибки под полями;
   заполнить — запись появляется на странице кофейны и в блокноте,
   удаляется кнопкой «Удалить». Перезагрузка страницы записи
   не стирает (localStorage).
6. Вкладка Network: на разной ширине загружаются разные файлы
   изображений (`-480`, `-960`, `-1440`).
