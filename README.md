# Daily Cup — кофейный клуб

Гид по кофейням города, который пишут сами любители кофе. Каталог
можно фильтровать по району, цене капучино и способу заваривания;
у каждой кофейны — оценки клуба по вкусу, бариста, атмосфере и цене,
отзывы и фото. На главной — топ месяца.

## Что уже работает

- Каталог с комбинируемыми фильтрами (район, цена, способ заваривания),
  состоянием «ничего не найдено» и синхронизацией с адресом страницы.
- Страница кофейны: фото (с увеличением), описание, оценки по критериям,
  отзывы, способы заваривания, часы работы.
- Формы «Оценить кофейню» и «Предложить новую» с проверкой полей.
  Первая версия работает без сервера: записи сохраняются в браузере
  посетителя (localStorage) и собираются в его личный блокнот.
- Топ месяца на главной по среднему баллу клуба.
- Страница «О клубе»: методика оценок, вопросы и ответы, авторы фото.

## Дорожная карта

- Сервер и отправка отзывов и предложений в клуб.
- Публикация отзывов после модерации, настоящие адреса и часы.
- Новые районы и расширение каталога.
- Поиск и сохранение любимых кофеен.

## Технологии

- HTML5: семантика, `<picture>`, `<dialog>`, формы.
- CSS3: Custom Properties, Flexbox, Grid, медиазапросы Mobile First.
  Без фреймворков и сборки.
- Ванильный JavaScript: меню, фильтр, формы, блокнот.

## Запуск

Статический сайт: достаточно открыть `index.html` через любой
статический сервер, например:

```bash
python3 -m http.server 8000
```

Без сервера страницы тоже открываются, но localStorage может работать
с ограничениями в некоторых браузерах.

## Структура проекта

```text
daily-cup/
├── index.html          — главная: hero-блок, топ месяца, статистика
├── catalog.html        — каталог кофеен с фильтром
├── product.html        — страница кофейны (?id=<slug>)
├── order.html          — «Участвовать»: оценить / предложить, блокнот
├── contacts.html       — «О клубе»: методика, FAQ, авторы фото
├── css/
│   ├── style.css       — базовые стили (Mobile First)
│   └── responsive.css  — адаптивные стили, подключён после style.css
├── js/
│   ├── cafes.js        — данные кофеен первого выпуска
│   └── main.js         — меню, фильтр, диалог, формы, блокнот
├── images/             — фото: 480 / 960 / 1440 px, JPG + WebP
├── lighthouse/         — отчёты проверки доступности
└── README.md
```

## Адаптивность и доступность

- Mobile First, проверенные ширины: 360, 430, 768, 1024 и 1440 px.
  Горизонтальной прокрутки страницы нет ни на одной.
- Мобильное меню под кнопкой, сворачиваемый фильтр, сетки
  1 → 2 → 3 → 4 колонки, форма в одну колонку на телефоне.
- Responsive images: `<picture>` + `srcset`/`sizes`, WebP с JPG-запасом,
  три размера каждого фото.
- Таблица оценок на мобильном превращается в карточки.
- Skip-link, видимый фокус, label у полей, осмысленные alt, контраст,
  `<dialog>` с закрытием по Esc, `prefers-reduced-motion`.
- Lighthouse, Accessibility: **100 / 100 / 100** (index, catalog, order).
  Отчёты в `lighthouse/`.
