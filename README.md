# Relay

Сайт AI-платформы на этапе раннего доступа. Четыре страницы: главная, каталог моделей, информация о платформе и заявка на подключение. Нативные HTML, CSS и JavaScript, без фреймворка, сборки и внешних runtime-зависимостей.

## Страницы

| Страница | Содержание |
| --- | --- |
| `index.html` | Сценарии использования, примеры формата запроса, подборка моделей, калькулятор объёма токенов и FAQ |
| `models.html` | Поиск, фильтры по задаче и контексту, сортировка, характеристики моделей и переход к заявке |
| `about.html` | Назначение платформы, принцип работы, аудитория, стадия проекта и контакты |
| `waitlist.html` | Создание локальной заявки, подтверждение, редактирование, скачивание JSON и удаление |

Общие header, main и footer присутствуют в HTML каждой страницы. В футере навигация и контакты с SVG-иконками; в нижней строке только копирайт. Дополнительные сведения о хранении данных открываются в диалоге, а не на пятой странице.

## Локальный запуск

Из папки `relay`:

```bash
python3 -m http.server 8782 --bind 127.0.0.1
```

Откройте http://127.0.0.1:8782/.

Python раздаёт статические файлы. Переменные окружения, API-ключи, npm и установка зависимостей не нужны. Для ES modules и браузерных API используйте localhost или HTTPS, не `file://`.

Сайт совместим с размещением в подкаталоге GitHub Pages: ссылки и ресурсы относительные. Ожидаемый адрес после переименования репозитория и публикации: https://sho6ot.github.io/relay/. Переименование локальной папки само по себе не меняет имя или публикацию на GitHub.

## Возможности

### Каталог

- Шесть моделей со ссылками на первоисточники разработчиков.
- Поиск по названию, автору, задаче, описанию и тегам.
- Фильтры по задаче и минимальному размеру контекста; сортировка по названию и контексту.
- Состояние пустой выдачи и сброс фильтров.
- Диалог с характеристиками и ссылкой на исходную карточку.
- Выбранная модель передаётся в форму через `waitlist.html?model=...`; неизвестный идентификатор не создаёт фиктивную модель.

Все модели обозначены как подборка для планируемого пилота. Каталог не утверждает, что Relay уже предоставляет к ним доступ. Контекст указан по карточкам авторов, может требовать отдельной настройки и не является гарантированным лимитом Relay. Лицензии и условия развёртывания необходимо проверять по исходным материалам. Упоминания авторов не означают партнёрство.

### Калькулятор

Калькулятор оценивает объём, не стоимость:

```text
запросов за период = запросов в день × рабочих дней
входных токенов = запросов за период × средних входных токенов
выходных токенов = запросов за период × средних выходных токенов
всего токенов = входных + выходных
```

Расчёт выполняется целыми числами `BigInt`. Диапазоны: 1–1 000 000 запросов в день, 1–31 рабочий день, 0–10 000 000 токенов каждого типа на запрос. Входной и выходной объём не могут одновременно быть нулевыми. Дробные, отрицательные и некорректные значения не превращаются в правдоподобные результаты.

Результат переносится в заявку как диапазон месячной нагрузки через параметр `tokens`. Это оценка на основе введённых средних значений, не токенизатор и не обещание фактического расхода.

### Примеры запросов

Переключение сценариев обновляет пояснение и JSON запроса. Примеры не вызывают AI-модели, не содержат ключей или выдуманных ответов. Кнопка копирования использует Clipboard API; если браузер запрещает запись в буфер обмена, текст выделяется для ручного копирования и выводится объяснение.

### Заявка на ранний доступ

- Обязательны имя, email, сценарий, диапазон нагрузки и согласие на локальное сохранение.
- Компания, модель и дополнительные детали необязательны.
- Валидация повторяется в слое сохранения, а не только в полях формы.
- Заявка сохраняется в отдельной IndexedDB `relay-waitlist`, версия 1, хранилище `applications`.
- В одном профиле браузера хранится одна текущая заявка. Повторное сохранение после редактирования обновляет её, сохраняя UUID и дату создания.
- После перезагрузки показывается сохранённое подтверждение.
- Изменения можно отменить; удаление требует подтверждения.
- Можно скачать фактическую копию записи в JSON.
- Ошибки хранилища видны пользователю, введённые данные не заменяются фиктивным успехом. Для ошибки начальной загрузки предусмотрен повтор.

**Заявка остаётся на этом устройстве и не отправляется команде автоматически.** Нет общей очереди, фиктивного порядкового номера, рассылки писем, оплаты или выдачи API-доступа. Для обсуждения используйте контакты на сайте. Не указывайте пароли, API-ключи и конфиденциальные сведения.

Данные привязаны к origin и профилю браузера. Очистка данных сайта или приватного профиля может удалить заявку. При необходимости скачайте копию. Импорт копии не предусмотрен.

Прежние браузерные данные других приложений не читаются, не переносятся и не удаляются.

## Интерфейс и доступность

- Единая светлая визуальная система, собственные SVG-иконки и знак Relay.
- Адаптивные страницы, мобильная навигация и поля без горизонтальной прокрутки всей страницы.
- Видимый focus, skip-link, подписи и ошибки полей, клавиатурное переключение сценариев.
- Нативные диалоги с закрытием по Esc, кнопке или фону и восстановлением фокуса.
- Плавные переходы без задержек появления содержимого; `prefers-reduced-motion` уменьшает движение.
- Кнопка «Наверх» появляется после прокрутки на 420 px. При уменьшении движения возврат мгновенный.
- Реальные состояния загрузки, пустой выдачи, ошибки и успешного сохранения.

## Проверки

Для автоматических проверок нужен Node.js с ES modules и встроенным `node:test`:

```bash
node --test tests/relay.test.mjs
```

Проверяются точные суммы токенов, предельная нагрузка, некорректные значения, обязательные поля и согласие, необязательная компания, неизвестные модели и ограничения длины.

В Chromium проверены поиск, фильтры и сброс, характеристики модели, перенос выбора и расчётной нагрузки в заявку, валидация, сохранение, HTML escaping пользовательского текста, отмена изменений, редактирование с сохранением UUID, перезагрузка, фактическая загрузка JSON и подтверждённое удаление. Все четыре страницы проверены на ширинах 360, 430, 768, 1024 и 1440 px без горизонтальной прокрутки страницы.
